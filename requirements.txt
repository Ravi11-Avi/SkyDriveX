1. ITEMS THAT ARE COMPLETELY EMPTY IN YOUR .env
--------------------------------------------------------------------------------
These 4 AWS variables are declared on lines 11-17 of backend/.env but have no values:

[ ] AWS_REGION=
    • What it is: The AWS region where your S3 bucket resides (e.g., us-east-1, ap-south-1).
    • Needed for: Storing uploaded files in AWS S3 cloud storage.
    • What happens without it: The backend automatically falls back to local disk 
      storage inside `backend/uploads/`.

[ ] AWS_ACCESS_KEY_ID=
    • What it is: IAM Access Key ID with S3 read/write permissions.

[ ] AWS_SECRET_ACCESS_KEY=
    • What it is: IAM Secret Access Key paired with the Access Key ID.

[ ] AWS_BUCKET_NAME=
    • What it is: The exact name of your S3 bucket (e.g., skydrivex-bucket).

2. ITEMS THAT ARE MISSING ENTIRELY FROM YOUR .env
--------------------------------------------------------------------------------
These configuration variables are not present in your backend/.env at all:

[ ] FRONTEND_URL=http://localhost:5173
    • Needed for: CORS authorization and OAuth callback redirects (Google & GitHub).
    • When you deploy frontend to Vercel/Netlify/custom domain, set this to your 
      production frontend URL (e.g., https://skydrivex.vercel.app).

[ ] SMTP EMAIL CONFIGURATION (Required for live password reset emails):
    Without these, password reset links print to your terminal console instead
    of sending an actual email:
    • SMTP_HOST=smtp.gmail.com (or your mail provider host)
    • SMTP_PORT=587
    • SMTP_SECURE=false
    • SMTP_USER=your_email@gmail.com
    • SMTP_PASS=your_16_digit_gmail_app_password
    • EMAIL_FROM="SkyDriveX Support" <noreply@skydrivex.com>

[ ] FILE UPLOAD & QUOTA LIMITS (Optional overrides):
    • MAX_FILE_SIZE_MB=100 (Default is 100MB per file)
    • STORAGE_QUOTA_BYTES=16106127360 (Default is 15GB per user in bytes)
